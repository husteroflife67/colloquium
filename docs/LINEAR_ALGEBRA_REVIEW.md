## Выполненная математическая самопроверка

При подготовке использовались точные символические вычисления SymPy:

- Для каждого найденного общего решения системы проверено тождество Ax−b=0; ранги сравниваются отдельно для несовместных случаев. Особые значения параметров повторно подставлялись в исходную матрицу. Если параметр только в правой части, учитывались также нули условий совместности, а не только ведущих элементов.
- Для обратных матриц проверялись произведения с исходной, для матричных уравнений — подстановка полученного X. Для вырожденных уравнений использовались обязательные соотношения строк/столбцов.
- Числовые определители вычислялись приведением к треугольному виду с учётом перестановок строк и сверялись с прямым определителем.
- Условия на члены определителя проверялись по уникальности обоих индексов, знаки — по числу инверсий. Члены старших степеней получены перебором всех перестановок порядка 4.
- Разложения перестановок в циклы и их степени вычислялись по отображениям. Для П178 проверено AXB=C в соглашении курса.
- Для доказательных и общих задач проверена логика применения линейности, знака перестановки, геометрической прогрессии нильпотентной матрицы и вырожденности.

Это самопроверка автора, а не независимая математическая экспертиза каждого решения. Синтаксическая проверка всех формул не доказывает их истинность.

## Инженерная проверка

- Контент-тест проверяет полноту диапазонов, уникальность ID, наличие каждого решения и источников, валидацию прогресса, соглашение перестановок и точные ссылки.
- Более 2800 математических фрагментов решений рендерятся без ошибок версией KaTeX из проекта. Краткая теория проверяется также при браузерном просмотре.
- Браузерные тесты охватывают скрытие ответов до запроса, оригиналы условий, увеличение и клавиатурный фокус, отметки после перезагрузки, поиск и закладки третьего курса, экспорт/импорт и старые копии, отображение всех карточек, ширины 320–768 и печать без изменения прогресса.
- Производственный сценарий проверяет доступ к сканам под префиксом GitHub Pages. Существующие тесты обоих прежних курсов сохранены.
